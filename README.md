# MGAP Variant Comparison Pipeline

## Overview
A multi-species bacterial variant-comparison workflow implemented using Snakemake and Python.
The pipeline processes variant and gene-detection tables generated by MGAP (Microbial Genomics Analysis Pipeline) from MGI and compares results across bacterial isolates belonging to the same species.
The aim is to identify differences between isolates and generate candidate variants for further investigation.

## Analyses
The workflow includes seven analyses:
1. **SNP comparison** — Compares reported variants across isolates and identifies variants not shared by every sample.
2. **Indel comparison** — Compares insertion and deletion calls across isolates and identifies variants not shared by every sample.
3. **CNV comparison** — Compares copy-number variation results and identifies variants not shared by every sample.
4. **SV comparison** — Compares structural variant calls and identifies variants not shared by every sample.
5. **Resistance gene comparison** — Compares detected antimicrobial resistance genes and identifies genes not shared by every sample.
6. **Virulence gene comparison** — Compares detected virulence genes and identifies genes not shared by every sample.
7. **Variant filtering summary** — Generates a summary of the variant and analysis.

## Project structure
- `Snakefile` — Snakemake workflow and analysis dependencies.
- `config.yaml` — Configured filtering and matching parameters.
- `scripts/` — Python scripts implementing the analyses.
- `data/` — Local input files, excluded from Git.
- `results/` — Generated reports, excluded from Git.
- `logs/` — Execution logs, excluded from Git.

## Input data
For every bacterial sample, the workflow expects these MGAP output files:
- `Anno_cnv.xls`
- `Anno_sv.xls`
- `variant.snp.ann.tab.xlsx`
- `variant.indel.ann.tab.xlsx`
- `Resistance.DNA.xlsx`
- `Virulence.DNA.xlsx`
Input files are organized by species and sample within `data/`.
The Snakefile automatically discovers species and samples and checks whether the required files exist.

## Configuration
Filtering and matching parameters are defined in `config.yaml`.
These currently include CNV read-depth ratio thresholds and reciprocal overlap, an SV score threshold, and coverage and depth thresholds for resistance and virulence gene analyses.
The SNP and indel comparison scripts do not currently apply additional sequencing-quality thresholds. They select variant types and exclude variants reported in all samples.

## Outputs
For each species, Snakemake defines the following reports:
- `variant_filter_summary.csv`
- `cnv_comparison_all.csv`
- `snp_comparison_all.csv`
- `indel_comparison_all.csv`
- `sv_comparison_all.csv`
- `res_comparison.xlsx`
- `vir_comparison.xlsx`
Outputs are written to `results/<species>/`.

## Current status and limitations
The repository is under active development.
The current workflow compares MGAP-generated results.
Variant representation, filtering assumptions, and the distinction between an absent variant call and a confirmed reference genotype require further evaluation.
Software dependencies, execution instructions and reproducibility testing will be documented as the project is prepared for wider use.

## Planned development
A subsequent phase will extend the Snakemake workflow with alignment-processing and inspection steps using tools such as BWA and SAMtools to support manual validation of candidate variants.

## Data availability
Clinical and workplace sequencing data are not distributed with this repository.
Users must supply appropriately MGAP output files to execute the workflow.
